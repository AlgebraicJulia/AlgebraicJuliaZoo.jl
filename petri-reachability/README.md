# Petri Reachability

From the paper "Mathematical programming approach to the Petri nets reachability problem" we reproduce the key mathematical programming representation of finding optimal paths from a start state to a desired end state in Petri nets. These reachability problems are important for process optimization, and Petri nets are a fundamental model of processes which can represent concurrency, parallelism, and conflict between processes. Process models can be optimized in a spectrum of ways. On one hand, process models can be treated as black boxes (e.g. complex stochastic simulators, agent-based models, etc) which allows extreme realism, but the optimization techniques which can be brought to bear are necessarily crude, as they do not have any insight into the model. Common techniques involve genetic algorithms and other heuristic search methods. On the other hand, the process model can be defined in such a way that an explicit mathematical representation (e.g. not arbitrary code) is possible. While this limits the expressiveness of the model, it allows uses to bring highly developed and efficient solvers to bear to optimize their process model. For a recent example of such a "white box" approach to process modeling for optimization, see <https://link.springer.com/article/10.1007/s10626-023-00387-7>.

The techniques explored from this paper stand at the white box end of the spectrum. They take a process model defined in a formal mathematical language (Petri nets), and apply mathematical programming to solve the reachability problem. The methods here should provide a good basis for further exploration of this type of process model optimization.
